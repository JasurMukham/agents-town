# Городок агентов

Пиксельная игра, в которой ИИ-агенты из Claude живут в офисах: у каждого проекта своё здание, у общих проектов — комнаты-отделы. Хозяева ходят по городку своими человечками.

Сайт: https://jasurmukham.github.io/agents-town/

Здесь только код. Все данные лежат в отдельном приватном репозитории, и сайт читает их по личному токену GitHub, который хранится только в браузере игрока.
